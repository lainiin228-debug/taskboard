# TaskBoard — доска задач

Тип: демонстрационный учебный проект, подготовленный с помощью ИИ.
Технологии: HTML, CSS, JavaScript, localStorage.

## Описание для портфолио
Локальное веб-приложение для планирования работы. Карточки распределяются по трём статусам: запланировано, в работе и готово. Реализованы создание, редактирование и удаление задач, поиск, фильтр приоритета, сохранение в браузере и экспорт CSV. Интерфейс адаптируется к узкому экрану.

## Что показывать
Откройте index.html, создайте задачу, переведите её в работу, обновите страницу и выгрузите CSV. В preview.jpg показан стартовый демонстрационный набор.

## Проверено
Создание, редактирование, поиск, смена статуса, сохранение после перезагрузки, подтверждение удаления и скачивание CSV проверены через браузер. Мобильная компоновка реализована медиазапросами; отдельная проверка на реальном телефоне не проводилась.
